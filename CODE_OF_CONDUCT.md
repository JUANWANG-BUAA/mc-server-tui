# Code of Conduct

## Our pledge

We want participation in mc-server-tui to be harassment-free and useful for
everyone, regardless of experience, identity, background, or preferred server
loader.

## Expected behavior

- Be direct about technical problems, and kind about the person.
- Assume good faith; ask for reproduction steps instead of assigning blame.
- Respect private data: never post world files, tokens, IP addresses, or logs
  containing personal information without consent.
- Keep reviews focused on the change, its safety, and the user impact.

## Unacceptable behavior

Harassment, threats, discriminatory language, doxxing, sustained disruption,
and publishing another person's private information are not acceptable.

## Scope and enforcement

This applies in repository issues, pull requests, discussions, reviews, and
other project spaces. Maintainers may edit or remove content, close threads, or
temporarily/permanently restrict participation when behavior violates this
policy. Reports can be sent privately to the maintainer via GitHub
(`@JUANWANG-BUAA`) or through a GitHub report; do not put sensitive reports in a
public issue.

This is a small alpha project. Enforcement is best-effort, but reports will be
reviewed in good faith and kept as private as practical.
