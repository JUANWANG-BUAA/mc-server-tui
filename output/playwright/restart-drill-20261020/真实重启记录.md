# 真实 Paper 受控重启记录

日期：2026-10-20

环境：macOS Apple Silicon；Paper 1.21.11 build 132；Java 27。

证据范围：真实 Paper 进程与真实世界副本，通过协议 v11 daemon API 驱动。

## 隔离方式

使用独立临时 state/cache/socket，将已有 `friends-night` 实例的
`instance.toml`、`lock.json` 和 `server/` 只读复制到临时目录，排除旧备份，
移除副本中的旧 supervisor 记录后启动。原始实例目录没有启动、写入或修改。

## 结果

| 步骤 | 观察 |
| --- | --- |
| 首次启动 | 从 `installed` 进入 `running`，Java PID 3482 |
| 受控重启 | 请求返回 `starting`，新 Java PID 3565 |
| 再次就绪 | 新进程进入 `running`，PID 保持 3565 |
| 再次停服 | 进入 `stopped`，退出码 0 |

结论：真实 Paper 的优雅停服、旧进程退出、替代进程启动和再次就绪均成功；
重启期间 PID 确实发生变化，停止结果没有异常退出码。

## 边界

- 本次没有 Minecraft 游戏客户端进入世界，也没有验证异地玩家连接。
- TUI 的 `/restart` 与 `R` 由实例详情 PTY 覆盖；本次真实演练直接验证 daemon
  协议和监督器，因此 UI 与真实 Paper 是两条相互补充的证据。
- 临时副本未复制到仓库；副本与空临时目录在验证结束后移入系统废纸篓。
