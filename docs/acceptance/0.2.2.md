# v0.2.2 acceptance — 2026-10-21

## Scope

Patch release of the unsigned alpha: first-use entry points, operation-failure
presentation, test integration, bilingual promotional pages and teaching guides.
API 8–11, state schema 1 and runner protocol 1 are unchanged.

## Local automated evidence

Executed on macOS Apple Silicon with the v0.2.2 workspace:

- Formatting, strict Clippy with all targets/features and a locked workspace build passed.
- `cargo test --workspace --all-targets --locked`: 258 passed, including 104 TUI tests; no failures or ignored tests.
- `cargo test --workspace --doc --locked` passed; there are currently no executable documentation examples.
- All five PTY flows passed: shell responsiveness, first-use, guided create,
  task detail and instance/backup/restore/lifecycle.
- First-use runs the real binary against an isolated fixture. It checks the
  three entries, failure evidence/dismissal, incomplete Fabric rejection, exact
  Fabric API dispatch and clean Ctrl-C exit.
- Real-daemon protocol-window checks passed using isolated state and a socket;
  current versions 8–11 are accepted and unsupported versions/operations rejected.

PTY fixtures do not start Java or download upstream artifacts. They validate
terminal input, output and API dispatch, not Minecraft world correctness.

The local optimized package was installed into isolated temporary prefix/root
directories. SHA-256/size verification, installed `mc version --json` (0.2.2,
release profile) and uninstall dry-run passed. No host service was changed.

## Website and teaching documentation

The English/Chinese landing pages and guides use one shared visual system.
Their release metadata and installer tags derive from the workspace version.
`python3 scripts/check_docs.py` checks repository documentation links/anchors,
local HTML links/assets/anchors, generated-page freshness and installer versions.
It does not check every external website or download availability.

Browser checks passed for all four pages at 1440px, 768px, 390px and 320px,
with no horizontal overflow, missing local assets or stale release text. Workflow
arrow/Home/End keys, seven theme previews and persistence, clipboard content,
clipboard-denied fallback, full-text chapter filtering, mobile chapter navigation,
reduced motion and all four pages without JavaScript passed.
New welcome/error captures use the v0.2.2 binary at an observed 80×24 size.
Screenshots are stored under `output/playwright/release-0.2.2/` for local review;
committed UI assets state their fixture provenance in the captions.

## Historical evidence and remaining work

The [v0.2.1 isolated real Paper drill](0.2.1.md) exercised startup, console,
graceful stop, verified backup, explicit restore, marker-file recovery and
post-restore readiness. It is not counted as a new v0.2.2 real-game drill.

Remaining acceptance: a real Linux user-service installation, external client
join, in-game post-restore world inspection and broader real failure injection.
