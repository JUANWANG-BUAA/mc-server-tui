# mc-server-tui 0.2.2

An **unsigned alpha pre-release** that connects the first-use experience,
operation failures and documentation to the behavior you can actually use.

## What changed

- The default session and classic dashboard share Paper, Fabric and import
  entries. Paper opens the wizard; Fabric prepares an editable `/fabric ` draft
  and requires a name, exact version and explicit EULA acceptance.
- Operation failures show the backend reason and recovery advice. `d` / F3
  expands evidence; arrows or the mouse wheel scroll; Esc / Enter closes.
  The underlying page and draft are preserved. No automatic retry or clipboard
  action is advertised. Connection polling failures remain inline.
- Error templates retain original evidence, error codes and retry policy.
  Previously disconnected tests now run, and the error-handling example builds.
- Both landing languages and both teaching guides have been rebuilt around
  installation, creation, daily operation and recovery. The guides include
  expected results, troubleshooting, searchable chapters and screenshots whose
  demonstration data is explicitly labelled.
- CI now checks all Rust targets, first-use PTY behavior, documentation paths and
  anchors, generated-page freshness and installer-version consistency.
- Duplicate completion reports and committed browser scratch files were removed;
  the maintenance status records reproducible checks and the remaining limits.

## Install

```sh
TAG=v0.2.2
curl -fsSL "https://github.com/JUANWANG-BUAA/mc-server-tui/releases/download/$TAG/install.sh" | sh
mc setup
mc
```

Artifacts: macOS 13+ Apple Silicon, GNU Linux x86_64 and GNU Linux arm64. There
is no Intel macOS or Windows artifact. SHA-256 and size checks do not replace a
publisher signature or Apple notarization. Keep an independent world backup.

## Upgrade and compatibility

API **8–11**, state schema **1** and runner protocol **1** remain unchanged.
Finish active download, backup and restore work first; update-time task draining
is not implemented. Exit the old TUI, install the new versioned package, run
`mc service restart`, then reopen `mc` and check `mc version --json`.
Resident runners hold running Java processes independently of the daemon.

Task history is durable. Unfinished tasks become `interrupted` after daemon
restart and are not automatically replayed. Retained partial download files may
be reused by a later attempt. `mc update rollback --dry-run` previews program
rollback; program rollback does not restore a world.

## Validation and limits

Local macOS checks: 258 Rust tests (104 TUI), formatting, strict all-target
Clippy, build, five real-binary PTY flows and the isolated real-daemon protocol
window. Website validation covers both languages, desktop/mobile layouts,
workflow tabs, theme switching, copy controls and chapter navigation.
See the [acceptance record](https://github.com/JUANWANG-BUAA/mc-server-tui/blob/v0.2.2/docs/acceptance/0.2.2.md).

The prior real Paper backup/restore drill is historical evidence from v0.2.1.
This release does not add real client world verification or a real Linux
user-service drill. Vanilla, existing-directory takeover, online/scheduled
backups, broader property editing and signed automatic updates remain future work.
