# mc-server-tui 0.2.0 — unsigned alpha

`v0.2.0` is an unsigned alpha pre-release. It is a substantial extension of the
first public alpha, not a stable-release claim.

## Highlights

- Paper and Fabric server creation, verified downloads, resident supervision,
  console access, logs, stopped-world backup and restore.
- Workspace pages, log search/filtering, CPU/RSS history, player actions, and
  non-destructive operational alerts.
- Modrinth add-on installation, MRPACK/ZIP server-pack preview and
  stopped-instance import, plus verified server-pack export.
- A four-field `server.properties` editor with diff review, external-edit
  conflict detection, and atomic save.
- Controlled `/restart` with a coordinated graceful stop and start sequence.
- Actionable startup diagnostics for common Java, port, EULA, memory, and
  `server.jar` failures.
- API protocol 11 with an accepted v8–v11 compatibility window, runner protocol
  v1, versioned update status, and manual rollback.

## Verification

- 217 macOS workspace tests pass, including 91 TUI tests.
- Strict Clippy and formatting checks pass.
- Four PTY interaction suites pass against fake daemons.
- The isolated real-daemon protocol window check passes from v8 through v11.
- A real Paper 1.21.11 restart replaced a running process (PID 3482 → 3565),
  returned to readiness, and stopped with exit code 0.

## Install

`v0.2.0` is published as a pre-release, so use the tag-specific installer:

```sh
TAG=v0.2.0
curl -fsSL "https://github.com/JUANWANG-BUAA/mc-server-tui/releases/download/$TAG/install.sh" | sh
mc setup
mc
```

The installer verifies the release manifest's SHA-256 and size. It does not
provide code signature or macOS notarization verification.

## Known limitations

- Unsigned and unnotarized artifacts; no Homebrew tap, apt/dnf repository, or
  signed automatic updater yet.
- No Vanilla provider and no takeover of an existing server directory.
- `server.properties` coverage is limited to MOTD, maximum players, difficulty,
  and view distance; raw editing and the full property catalog are pending.
- Backups are stopped-world only; scheduled/online backups remain pending.
- Forge/NeoForge and CurseForge file-ID materialization are not implemented.
- A Minecraft client join and post-restore in-game world verification still
  need a real client drill.
- Linux systemd behavior is covered by CI tests but still needs a real-host
  service installation drill.
- State migrations and update-time task draining are not implemented.
