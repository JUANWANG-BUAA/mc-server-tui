# mc-server-tui 0.2.1

An **unsigned alpha pre-release** focused on clearer daily operation. The server
context stays visible, console commands have an explicit target, and advanced
settings leave more room for the task at hand.

## What changed

- Selected instance, state, next action and resources stay above the transcript.
  Background progress has one summary; management connectivity is distinct from
  Minecraft readiness.
- Console drafts retain their original target across instance switches. Return
  to that instance or clear the draft before sending.
- Paper runtime setup starts with a summary showing name, version, Java, memory
  and port. F3 / Tab opens adjustment; Java recommendations follow game version.
- F3 expands instance diagnostics and backup evidence; logs receive more space.
  Backup details show local time and offset. Restore previews explain replacement
  scope and that later world progress is not merged.
- Backup operation titles describe the current action, from creation to restore.
- English/Chinese guides and the promotional site now describe the same release,
  with refreshed screenshots and a corrected three-target platform list.

## Install

```sh
TAG=v0.2.1
curl -fsSL "https://github.com/JUANWANG-BUAA/mc-server-tui/releases/download/$TAG/install.sh" | sh
mc setup
mc
```

Artifacts: Apple Silicon macOS, Linux x86_64 GNU and Linux arm64 GNU. Intel
macOS and Windows are not included. The installer checks SHA-256 and size;
artifacts are not signed or notarized. Keep an independent world backup.

## Compatibility and upgrade

API window **8–11**, state schema **1**, runner protocol **1** are unchanged.
There is no state migration in this release. Exit the old TUI, install the
versioned package, restart the management service with `mc service restart`,
and reopen `mc`. Running Java instances belong to resident runners; restarting
the management service does not intentionally stop them. Update-time task
draining is not implemented: finish active backup/restore/download work first.
Use `mc version --json`, `mc status --json` and `mc update status` to inspect.
`mc update rollback --dry-run` previews a switch to a retained prior version;
program rollback does not restore world data.

## Validation and limits

224 workspace tests (98 TUI), strict Clippy, formatting, build, four PTY suites
and real-daemon v8–v11 checks passed locally on macOS. A real isolated Paper
1.21.11 build 132 drill covered startup, console, graceful stop, verified backup,
explicit restore, marker-file content recovery and post-restore readiness.
See the [acceptance record](https://github.com/JUANWANG-BUAA/mc-server-tui/blob/v0.2.1/docs/acceptance/0.2.1.md).

No Minecraft client joined in this drill. In-game world inspection and real
Linux service installation remain unverified. Online/scheduled backups, Vanilla,
complete property editing, signed updates and task draining remain future work.
