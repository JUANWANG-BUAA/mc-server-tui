# mc-server-tui 0.1.0 — unsigned alpha

This is the first public alpha pre-release. It is **not signed or notarized**;
the installer verifies the release manifest's SHA-256 and size, but not a code
signature. Keep independent backups of any world you care about.

## Install

`v0.1.0` is a pre-release, so GitHub's `/latest/` URL does not select it yet:

```sh
TAG=v0.1.0
curl -fsSL "https://github.com/JUANWANG-BUAA/mc-server-tui/releases/download/$TAG/install.sh" | sh
mc setup
mc
```

Requirements: macOS 13+ or Linux x86_64/arm64, Java 21+, terminal at least
80×24, network access for the first Paper download.

## What is included

- Paper creation, exact-build downloads, SHA-256 verification, resumable cache.
- Resident per-instance runner that survives TUI/daemon restarts.
- Idempotent start, graceful stop, console input, incremental logs, CPU/RSS.
- Durable tasks with byte progress, speed/source, event cursors, cancellation.
- Session-first TUI with command completion, palette, cursor editing, seven
  themes, pixel Steve, mouse support, 80×24 and 40×12 render coverage.
- Stopped-world backup, paged verification, restore preview/token, transaction
  and recovery journal.
- Read-only `.mrpack` analysis: MC version, loader, `env.server`, unsafe paths,
  hashes, download hosts.
- `mc` launcher, `config.toml`, launchd/systemd user service, versioned
  installer, release manifest and Homebrew formula.
- Four release targets: macOS arm64/x86_64 and Linux x86_64/arm64.

## Known limitations

- Paper only; no Vanilla, Fabric, or actual `.mrpack` import.
- No takeover of existing server directories.
- Stopped-world backups only; no online or scheduled backups.
- No `server.properties` editor, player management, or server build updater.
- No auto-updater, N/N-1 daemon protocol window, or signed releases.
- Linux systemd has CI generation/`systemd-analyze` coverage but no full
  real-host install drill.
- The default User-Agent points at the project repository; forks should set
  their own contact.

See [Implementation gaps](https://github.com/JUANWANG-BUAA/mc-server-tui/blob/main/docs/IMPLEMENTATION_GAPS.md) for the full audit.

## Assets

The release contains:

- `mc-server-tui-0.1.0-<target>.tar.gz` for four targets;
- matching `.sha256` files;
- `release-manifest.json` (version, API protocol, state schema, target hashes,
  URLs);
- `install.sh` with the tag-specific manifest URL;
- `mc-server-tui.rb` Homebrew formula (tap not yet published).
