# 首次使用体验优化总结

## 实施日期
2026-10-21

## 改进概述

本次优化专注于提升新用户的首次使用体验，让用户能够快速上手 MC Server TUI。

### 1. 欢迎界面 (`welcome_view.rs`)

**功能**：
- 在没有实例和任务时自动显示欢迎界面
- 显示 Steve 像素头像（8x8 像素艺术）
- 提供三个明确的入口点：
  - 按 `n` 创建 Paper 服务器
  - 按 `f` 创建 Fabric 服务器（预留）
  - 按 `i` 导入现有整合包
- 显示常用快捷键提示
- 支持紧凑模式和完整模式布局
- 可点击的操作卡片

**实现细节**：
- 完整模式：宽度 ≥ 70 且高度 ≥ 20
- 紧凑模式：宽度 < 70 或高度 < 20
- 自动布局调整，优先显示关键信息
- 像素艺术使用 Unicode 方块字符

### 2. 上下文感知的引导提示系统 (`contextual_hints.rs`)

**功能**：
- 根据当前应用状态动态生成上下文提示
- 支持多种提示类型：
  - 首次使用
  - Java 未找到
  - 服务器已停止/运行中/启动中/失败
  - 任务进行中/失败
  - 常规操作

**提示内容**：
- 主要消息：描述当前状态
- 操作列表：最相关的 3-5 个快捷键
- 状态图标：视觉化状态指示
- 颜色编码：成功(绿)、警告(黄)、错误(红)

**使用场景**：
```rust
let hint = ContextualHint::from_app_state(app);
let status_line = hint.render_as_status_line();
let actions_line = hint.render_actions_line();
```

### 3. 点击交互增强 (`hit.rs`, `app.rs`)

**新增点击目标**：
- `WelcomeCreatePaper`：点击创建 Paper 服务器
- `WelcomeCreateFabric`：点击创建 Fabric 服务器
- `WelcomeImportModpack`：点击导入整合包

**事件处理**：
- 集成到现有的 `apply_click` 函数
- 自动触发对应的 Action
- 支持鼠标双击增强

### 4. 视图集成 (`view.rs`)

**渲染逻辑**：
```rust
// 在 render_dashboard 函数中
if app.instances.is_empty() && app.tasks.is_empty() 
   && area.width >= 60 && area.height >= 15 {
    crate::welcome_view::render(frame, area, app, hits);
    return;
}
```

**触发条件**：
- 没有实例
- 没有任务
- 窗口尺寸足够（宽度 ≥ 60，高度 ≥ 15）

## 设计原则

### 1. 渐进式披露
- 首次使用时只显示最关键的操作
- 高级功能通过命令面板 (`/`) 访问
- 避免信息过载

### 2. 上下文相关
- 根据当前状态显示最相关的提示
- 动态调整快捷键建议
- 状态驱动的引导信息

### 3. 视觉层次
- 使用图标和颜色编码传达状态
- 关键操作使用 keycap 样式突出显示
- 保持低对比度主题风格

### 4. 可访问性
- 全键盘可达
- 鼠标操作为可选增强
- 明确的视觉反馈
