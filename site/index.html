02

A per-instance runner owns Java's console. Close the TUI, restart the daemon, or update the management layer; the Minecraft process keeps running and reattaches.

resident supervisor

Downloads with receipts.

Paper builds are locked to an exact build, size, and SHA-256. Resume is only used when the source proves the range; the installed bytes are verified before they become an instance.

Architecture

The UI is disposable.
The server isn't.

The TUI and CLI are clients. A local daemon owns tasks and supervision. Each instance has a detached runner that holds Java's stdin/stdout/stderr and a private control socket.

  • Daemon restart → reattach, don't kill Java
  • Process identity must match before any signal
  • World writes go through leases and recovery journals
  • Unix socket is per-user, mode 0600

Get started

One command.
Then it's yours.

Install the alpha user-local, write a config, verify Java, and install a launchd/systemd user service. No browser, no root, no daemon left in a random terminal.

install.sh / unsigned alpha 
$ TAG=v0.2.0
$ curl -fsSL "https://github.com/JUANWANG-BUAA/mc-server-tui/releases/download/$TAG/install.sh" | sh
$ mc setup
$ mc
SHA-256 verified not signed yet tag-specific install

Alpha note: v0.2.0 is a pre-release, so GitHub's /latest/ URL does not select it yet. The installer checks the manifest hash and size, but not a code signature. Keep an independent world backup.
