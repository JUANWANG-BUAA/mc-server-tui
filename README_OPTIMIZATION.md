## 🎓 核心洞察

### 产品定位重塑

**从**：像 PCL 的低门槛终端工具（模糊）  
**到**：技术服主的可靠管理工具（清晰）

**目标用户**：
- ✅ SSH 管理多服务器的技术人员
- ✅ 重视数据安全、需要可验证备份
- ✅ macOS 准备 + Linux 部署

**不是**：
- ❌ 零门槛的新手工具
- ❌ 多用户商业面板

### 功能优先级重排

**P0（必须完成）**：
- Vanilla、接管目录、在线备份
- 完整属性编辑、客户端验证
- macOS 签名、Homebrew/apt 安装

**应延后（已实现但非核心）**：
- 7 个主题（减少到 3 个）
- 装饰性功能
- 小众集成

### 交互体验改进

**简化**：
- 6 标签页 → 3 标签页
- 多页面工作区 → 评估简化
- 卡片式实例列表

**引导**：
- 首次使用欢迎界面
- 上下文相关帮助
- 三段式错误信息
